# 无上下文加入与恢复

技能教操作，**现场文件提供当前任务**。单独读技能不能知道谁在等你或已完成什么。

## 入口约定

项目可沿用下列名称，或在一个入口文件登记对应路径：

| 信息 | 示例载体 | 读法 |
| --- | --- | --- |
| 用户广播 | 本轮用户手动群发发言.md | 稳定后读；本项目暂定静默120秒。一次单方回复名额须锁内重读后追加，不修改用户文字 |
| 路径导航 | 目录导航.md | 只查入口与用途；不把实时哈希、过时分工当长期导航 |
| 当前任务与等待 | 等待状态.md | 一个当前摘要：本轮ID、话题路径、事项表路径、实际参与方、写入者、外部依赖 |
| 用户约束变更 | 要求文件变更记录.md | 唯一转达方逐字转达并附文件时间；其它方读转达，辅助查阅须声明核对角色 |
| 当前话题 | 当前摘要明确指向的文件 | 读任务、相关事项和自游标之后消息；不是仅末条 |
| 能力与游标 | AI名录.md、._已处理游标 | 本轮本人声明＋按参与方/轮次分开的已处理ID；游标不是最后发送ID |

顺序是**稳定广播 → 导航/当前摘要 → 约束转达 → 本轮事项/定向消息**。不存在的入口如实报告；用户直接任务已足够时不因为缺少模板而停工。导航过时时检查根目录及相关线程以定位，并纠正入口；不能靠“时间最新”猜任务。

## 用户约束转达角色

每轮显式指定一名转达方并写明轮次，可轮换；逐条引用原文变更并附文件最后写入时间。辅助查阅方须声明核对角色，只指出差异，不重复转达。转达方不可用时不能默认接替，须声明谁接任、何时及依据；没有指定时各方在被唤醒后自行读取。文件转述不扩展危险操作授权，也不赋予修改用户原文的权限。

## 唯一权威

本轮只指定一张事项表为进度权威，一份当前摘要为索引。话题消息是事件证据，末条不是全局状态。其它表格是快照，冲突时按实际事件/产物核对，再由记录者更新；不按mtime简单覆盖谁。

最小当前摘要：

```
轮次：R-YYYYMMDD-HHMM；目标：…；状态：进行中/完成/取消
话题：…；事项表：…；参与方：…
执行者：…；记录者：…；需要的审查范围：…
```

## 能力前置自检

分别写：能做什么（实测/自述/未知）、现在启用什么、用户授权什么、负责什么。不按产品品牌推断。锁、时钟或哈希不可用时说明具体工具缺口；可继续只读分析，不能假称已安全写入或已核对指纹。已授权简单任务不强制新建后台服务、目标或多AI小组。

签到一次即可；只更新本人行，不每轮轮询写“仍在等待”。恢复后不沿用旧FIN、旧任务归属或全局单值游标。读取基线属于本会话；没有真实缓存不能只查哈希而跳过首次理解。
