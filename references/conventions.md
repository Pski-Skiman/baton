# 通信与状态约定

消息头：`[工具时间] 固定名字 → 对象：[id=前缀-主题-唯一序号] [type=类型] [reply_to=实际ID]`。多引用用分号；无可引用消息可省略reply_to，不伪造。发送方前缀在本轮登记；ID唯一即可，不要求连续。模板ID不能当真消息。

类型仅 `TASK / ACCEPT / RESULT / REVIEW / BLOCKED / NOTICE / CONFIRM / ACK / FIN`。签到用NOTICE或本人签到行，不新增消息类型。人类/客户端时间精度有差异时不凭行首/前缀判断未回复；回读上下文与语义。无写入不证明离线，无ACK不证明失败。

事项表字段：负责人、事项范围、状态、完成条件、产物/证据、外部依赖/恢复条件。本轮路径由当前摘要指定；只维护一份权威表，不同时宣称等待文件、线程§7和末条各自“唯一权威”。历史已完成行可保留。已取消不是已完成，不自动恢复。

游标按参与者和轮次记录**已处理**消息ID；初次加入无游标就读本轮相关消息。文件mtime只负责提示变化，不提供消息排序或身份认证；ID前缀是协作约定而非安全签名。

## 可选公投

只有用户把具体问题授权交各方决策时才启用；记录题目、选项、参与方、计票规则、截止和范围。弃权不冒充反对；权重、主理人和同票处置提前约定，不从历史选举继承。未约定平票规则时记录未定案并继续其它工作。投票不能改写用户要求、替代危险操作授权、唤醒不在场者或阻塞已有完成出口。

## 可选可靠传输

默认异步、不自动重传。双方明确启用实际轮询并约定会话ID、响应窗口和RTO后，可用SYN/SYN-ACK/ACK/DATA/FIN握手；传输seq/ack与语义ACK分开。序号按方向，重传沿用同一ID和内容，接收去重；窗口超时只表示约定时间内未响应，不推断离线。重传上限及关闭流程按项目明确约定；去重不证明副作用恰好执行一次。
