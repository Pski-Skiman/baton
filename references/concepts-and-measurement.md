# 与经典计算机概念的对应边界（含测量方法）

> **性质声明**：下面是**启发式类比**，用于**解释**本协作机制，**不表示**本实现具备数据库 / 操作系统 / 网络协议的同等保证。
> 这些措施**降低的是明确范围内的风险，不保证全部正确**；结论也不来自类比是否成立。
> 本节内容**经独立审查修正**（审查记录不随本文件发布）。**官方来源**：[PostgreSQL 事务隔离](https://www.postgresql.org/docs/current/transaction-iso.html)、[SQLite 原子提交](https://www.sqlite.org/atomiccommit.html)、[RFC 9293（TCP）](https://www.rfc-editor.org/rfc/rfc9293.html)。结论**限定于本协作实现**。

## 1. 读写互斥 / 隔离级别

- 本方法提供的是**协作式互斥**：当**所有参与者都遵守同一把锁**、且**短读写全部在临界区内**时，可以排除这些参与者**在该范围内**的并发冲突。
- **不提供** SQL 隔离级别、快照隔离、可串行化。
- **不覆盖**：锁外读取、跨文件工作流、进程崩溃。
- 「只追加」**本身不保证**不丢行、消息完整或没有交错。
- 实测坑：原「先判断不存在、再创建」存在 **TOCTOU 竞态**，已改为原子创建。

## 2. 事务 ACID（结论：未实现完整 ACID）

- `CreateNew` 只让**抢锁**这一步原子，**并不使整个写入成为事务**；`$acquired` 的作用是**防止误删他方锁**。
- **A 原子性：未实现**。追加中途失败可能**留下部分内容**，**没有回滚**。
- **C 一致性**：属**规则 / 不变量**层面的保持；**回读校验只能检查明确字段、编码与指纹**，**不能证明语义一致**。
- **I 隔离性**：仅为**协作方临界区**的有限互斥。
- **D 持久性**：**`finally` 释放锁与持久性无关**；回读**不能证明断电安全**。
- **结论**：本实现**参考 ACID 来审查缺口**，但**没有**实现完整 ACID。**不要为了类比而引入数据库或日志系统。**

## 3. 端口连接 / 可靠传输

- 文件信道**没有真实端口或套接字**；「AI 名 + 话题/会话 ID」是**逻辑寻址**，**不是**真实网络连接。
- `seq` **按消息条数计数**，**不等同于 TCP 的字节序号**。
- **去重不自动保证副作用「恰好执行一次」**（需要业务侧自己保证幂等）。
- 结论收窄为：**未约定活跃轮询时，超时无法判失败**。（不要写成「RTO 必然误报」这种绝对表述。）

## 4. 死锁 / 饥饿

- **持锁等回复**、**循环任务依赖**会产生**协议等待环**。
- 「互相谦让」更准确的叫法是「**责任未定导致的等待停滞**」，**不必**都称作经典资源死锁。
- **忙等抢锁没有公平性保证**；短临界区与显式指定执行者可以**缓解**，但**不能承诺无饥饿**。
- **久未被唤醒 ≠ 已发生锁饥饿**，两者不能混为一谈。

## 5. 文件系统

- 编码、路径、**搬迁后引用更新**、**单一权威源**都相关。
- **mtime 只代表「文件最后一次被修改」**，**不代表**消息排序，**也不代表**对方在线。
- **回收站元数据不必写进主技能**（避免无关的隐私扫描）。
- **文件或写入者退出，不保证锁文件自动清除**；**残留锁只报告，不得凭年龄自动删除他方锁**。

## 6. 进程调度

- **客户端/用户负责实际唤醒**；AI **不能承诺跨会话调度**。
- 「没有后台轮询 / 任何超时都不可靠」**过于绝对**：**本次活动会话内是可以轮询的**；双方约定**活跃响应窗口**时，**超时可用**；**仅仅**不保证会话结束后的自动唤醒。

# 测量方法（以及它不能证明什么）

- **字节数是「某个明确集合的载入体量」**，**不是**实际 token、不是费用、也不是缓存命中率。
- **情景假设一**（要求文件 3 读 vs 2 读）是**算术情景**，**不是**观察到全流程少用了 33.3% 的 token。完整口径必须计入：**转达、辅助核对、协议消息、技能正文、以及输出本身**。
- **情景假设二**（最小恢复集 vs 根目录全读）用「根目录全读」作为**假设基线**，**不证明**过去真的全读；**新文件起步更小 ≠ 相同任务的总成本更小**。
- → 因此这些数字**一律标注为「静态情景测算」**，并**报告具体集合与缺项**；**收益记为「待验证」，不宣称已实测省 token**。
- **默认恢复集应按角色读取转达**（主读取方读要求文件并转达），**不应让所有方再去读要求原文**。
- **帧指纹（SHA-256）只证明「相同范围的字节」**，**不能替代首次理解与审查**；它**只在已审内容未变时**省掉重复通读。
- 若要给出真实 token 数字，**必须先用真实分词器实测一次**；否则就是「看起来精确的估算」。
