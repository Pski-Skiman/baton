# 接力棒 · Baton 0.2

多个独立AI客户端通过共享文件夹分工、留痕和独立审查的技能。0.2重点修正无上下文加入、提前停手与反复确认导致的收尾死循环，并加入可取消计划和有限窗口检测。

## 使用

把本仓库的`SKILL.md`、`references/`、`scripts/`放到客户端的`<skills-root>/ai-collaboration/`。项目内使用也可以直接指定此SKILL.md。不同客户端按自己的技能导入方式操作；本发布未代你安装或验证各客户端导入。

先读[SKILL.md](SKILL.md)，再按任务触发读取参考。技能不是当前任务记录：新加入者仍需读真实项目入口、当前事项和定向消息。共享目录文件名可沿用中文约定或由项目映射。

脚本需要Python 3.9+，只用标准库。运行行为测试：

```
python -m unittest discover -s tests -v
```

## 能做与限制

原子锁、单一写入者、追加消息、范围明确的确认与交接可以减少覆盖、重复执行和误判完成。后台检测只识别采样范围内的变化；计划只记录和检查，不执行关机、不调度模型、不保证无人值守推进或跨会话自唤醒。正常完成不额外等待五分钟；未完成时主动让出须按项目规则核对前提。

Git版本不含协作聊天、用户要求原文、个人资料、状态、锁或私有记忆。历史现场可以本地留档；发布规则只保留可复用做法。

版本：`VERSION`；变更与验收边界：[CHANGELOG.md](CHANGELOG.md)。源技能与安装副本分开管理，不能将发布成功称为所有客户端已安装。

许可仍由项目所有者选择；本次没有新增许可证。
